`make figures` redraws the five marked "no" from the result tables and the
derived estimates, in SVG, PDF and PNG. The rest are shipped as SVG and PDF.

A note on Figure 1. Its final layout was assembled outside the numbered
pipeline, so no script in this repository reproduces it exactly. Every quantity
it plots is in `results/tables/`, namely `null_summary.tsv`,
`null_real_axes.tsv`, `null_pankbase_axes.tsv`, `model_lrt_Penn.tsv`,
`model_lrt_Vanderbilt.tsv` and the two `model_variance_decomposition_*.tsv`
files, so the panels can be checked against the stored numbers.

Every SVG keeps axis labels and tick text as real text, so the figures stay
editable in Illustrator or Inkscape.
